      自定义软件包（可选）

      仅支持 .ipk 或 .apk，并须与目标设备架构一致。请只上传来源可信的软件包：架构不匹配、依赖缺失或不兼容的包可能导致构建失败，甚至固件无法正常使用。单个文件不超过 100MB，软件包依赖的其他包需在已配置软件源中可获取。

      尚未上传软件包，点「上传软件包」添加。

      ① 填你自己的 fork 仓库（如 你的用户名/ZWRT）和你的 Token，构建就在你自己的 GitHub Actions 上完成，固件发布到你自己的 Release。
      ② Fork 后需先到该仓库 Actions 页点「启用工作流」，否则触发构建会报 404。
      ③ Token 权限：Classic PAT 勾选 repo 和 workflow；Fine-grained PAT 需勾选该仓库的 Actions 读/写。
      ④ Token 仅存本浏览器 localStorage，不上传本站服务器。
